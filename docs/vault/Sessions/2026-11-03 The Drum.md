## The drum (D152)

The user asked for the path to look as if it's on a rotating cylinder, left the details to the agent, and asked for critique agents to review and iterate. [[Client Build]] describes the result.

- **First build:** rows wrapped round a drum of 150 px, in 3D with `rotateX`. The text sheared (it looked italic) and squashed too hard, so it became a flat projection: a scale about each node, which keeps the spine straight, and a gentler flattening. A CSS rule's `all: unset` had reset the scaling's origin. Then a blank page after three answers: React error 185, an endless loop, because each render read the clock mid-turn, so measuring the lines always found a change. Fixed by letting Motion drive the turn, which the user's question about UI libraries also pointed to; no wheel-picker library fits a list that turns on answers, with measured lines and a flight into a row.
- **Round one of critique** (a visual designer and a usability specialist, as agents, from screenshots and the code): the turn bobbed down before turning up (the path's shift eased on another curve); the oldest answer vanished uncounted; text from about 30° failed contrast; focus on path rows was invisible (a bug from before the drum); hover was dead; the drum turned when any card arrived. All fixed: the shift snaps, a spring turn, a smaller drum (130 px, 58°, three answers), a front band, a spine that follows the drum, name cross-fades, hover and focus laying a row flat, the focus ring, "N earlier answers" as a button opening a "Your answers" panel, turning only when the card in play changes, and a flat list on phones.
- **Round two:** the visual critic found the band moving with the turn and washing out the lines, and rows dropped uncounted at the bottom; the usability critic found focus lost when opening an answer, the panel unreachable by keyboard, and two contrast failures. All fixed, with a browser test for the panel and focus. Left for later: list markup (`<ol>`) and visually hidden stakes text.
- **A flaky browser test** turned out to be a real, small defect: hover's easing also slid the rows into the drum as the page loaded.
