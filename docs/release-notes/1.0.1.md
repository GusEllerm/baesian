Baesian 1.0.1 makes the website quicker to move around, and shows on your projects page which projects have cards waiting for you.

## What's new since 1.0.0

- **Each project has an inbox** on your projects page at [baesian.dev](https://baesian.dev): a tray, empty when nothing waits, or holding a card with how many wait for you there, and which are hard or blocking, such as "3 waiting for you, 1 hard".
- **A project you've opened before in the tab shows at once.** Its desk appears from the copy the tab kept, marked "Refreshing…" until it's up to date, a second or two later. Answers wait until then, so you never answer a card someone has answered elsewhere in the meantime. Only the open tab keeps it: nothing is stored on your device, and signing out forgets it.
- **Opening a project reads it once,** where it was read twice, and the site's first page reads your account once.
- **The wordmark on a project's desk goes back to your projects without reloading the page,** so what the tab kept stays. With answers still waiting for your passkey, it leaves the page as before, so your browser asks first.
- The hosted service gains one read, `GET /v1/projects/{project}/waiting`, the counts the projects page shows.

No file format changed, and nothing changed in the command line, the plugin's behaviour or your git hooks.

## Updating

Update the CLI and the plugin together, so the plugin finds its own release on your PATH:

```sh
npm install -g baesian
```

Then the plugin. In Claude Code, from a terminal, then start a new conversation:

```sh
claude plugin update baesian@baesian
```

In Codex, then start Codex's interactive mode and accept its "Hooks need review" prompt:

```sh
codex plugin marketplace upgrade baesian
codex plugin add baesian@baesian
```

Nothing else needs running again. CI pinned to 1.0.0 by `baesian ci` keeps working; run `baesian ci` again only if you want it on 1.0.1.
