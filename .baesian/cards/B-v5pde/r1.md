crux_proposal: Yes
crux_alternative: Not needed
crux_fact: The root tests (`npm test`) run before the service's packages are installed in CI (`.github/workflows/ci.yml`). M9d's tests of the CLI against the relay start the service's Worker locally with Wrangler's `unstable_startWorker`, from `service/node_modules`, and skip themselves when it isn't installed. They take about 8 seconds, contact nothing but 127.0.0.1, and turn off Wrangler's metrics. The service's packages are installed in CI anyway, for `npm run test:service`.
rationale: They are the only tests that run the CLI and the relay together; skipped in CI, a change to either could break the other unseen. Moving one step costs nothing.
