crux_fact: Today the hooks run `baesian` from PATH and say nothing when it's missing; the MCP server's command is `baesian mcp`. Claude Code and Codex update a plugin only when its version changes, and neither updates the command line. The hooks use flags such as `inbox --session`. npx downloads a release the first time it runs it; the hooks' time limit is 30 seconds. Claude Code's plugin bin/ folder reaches its Bash tool, not git's hooks.
rationale: "One session, one release: agents' commands, the gate and the plugin all run the same `baesian`. A version check turns a mismatch into one clear message, rather than a hook failing on a flag it expected."
