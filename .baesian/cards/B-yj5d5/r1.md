crux_fact: The line holds the passkey's public key, the account's ID and handle, and when it was made; it can't be used to sign in. The same line reaches the repo's record from the relay, so CI's pin can be compared with it.
rationale: A public key needs no shown-once treatment, and asking a new person to save a line for a CI setting they haven't met yet is the hardest moment to ask it. The comparison it allows only catches a service that changed a key between sign-up and setup.
