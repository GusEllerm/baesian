crux_proposal: A second or two
crux_alternative: Half a minute is enough
crux_preference: true
crux_fact: Today the page asks each project for its count when it opens, and again when its tab comes back into view after being hidden. There's no timer, so a card filed while the page stays in view doesn't show until you reload. Each project already has a live connection that says when anything in it changes; a project's desk uses it. Holding one open costs next to nothing while the project is quiet, and the page would hold one per project (you have 2). While an agent waits on a card, its project says it changed every 30 seconds. Asking a project for its count takes 0.5 to 0.7 seconds of its work today, and much less once the state is kept (B-evrec).
rationale: "You'd just been told a card was filed, looked at the page, and it wasn't there: half a minute is long enough that you'd still reload. A project's desk already updates the moment a card arrives, and the projects page sits one click above it, so it should be no staler. The connection is one the service already has, and the page asks for a count only when something changed, where a timer asks every project every half minute whether anything did or not."
alternative_rationale: "A timer is the least that fixes it: a few lines, no connection to keep alive or to reopen when a laptop wakes, and nothing that grows with the number of projects but one small request each. How cards reach people's inboxes is about to be designed again for several reviewers, and whatever feeds the projects page then may replace this, so the simple thing is the right size for now. Half a minute is soon enough for a page nobody stares at."
wrong_if: a count on the projects page is behind the project's desk by more than a few seconds while both are open
check: open the projects page and a project's desk side by side, file a card, and watch both

Either way the page keeps asking when it opens and when its tab comes back into view, and shows what the tab last heard until the answer comes. With the live connection, the page reopens a connection that drops (a laptop waking, a network change) and asks that project again as it does, as a project's desk does.
